# Security policy

## Supported deployment

Security fixes are applied to the production deployment at [nutrica.fit](https://nutrica.fit).

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a concise report to `nutrica.life.app@gmail.com` with:

- a description of the issue and its impact;
- reproducible steps or a proof of concept;
- affected endpoint, page, or dependency; and
- a safe way to contact you for follow-up.

Reports are acknowledged as soon as practical. Do not include user data, credentials, API keys, or password-reset links in a report.
